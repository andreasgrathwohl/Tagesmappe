Frontstage – Logo-Varianten

Gewählt: „Heute“ (C2) – Gestaltungsbeschluss UI-1 in DESIGN.md. Sechs Entwürfe für das App-Icon aus drei Blickwinkeln, je von einem eigenen Subagenten mit genau einem Skill: A Apples Richtlinien für App-Icons, B Markenidentität, C eigenständige Formsprache. Gezeigt groß, auf dem Home-Bildschirm hell und dunkel, in 29 pt (kleinste Größe) und eingefärbt.

Die abgerundete Form schneidet iPadOS/macOS selbst zu; hier ist sie mit CSS nachgestellt. „Eingefärbt“ simuliert den Darstellungsmodus, in dem das System nur die Form in einer Farbe zeigt.
